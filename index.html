계산기 HTML 파일을 다시 드리고, GitHub에 올리는 최신 절차를 확인하겠습니다. **`index.html` 파일을 다시 보내드렸습니다.** 어제 만든 계산기와 같은 내용이며, 코드를 직접 복사할 필요 없이 파일을 그대로 올리면 됩니다. ## GitHub에 올리는 순서 (PC 권장) 1. [github.com](https://github.com)에 가입하고 로그인합니다. 2. 오른쪽 위 **+ → New repository**를 누릅니다. 3. 아래처럼 설정하고 **Create repository**를 누릅니다. - Repository name: `margin-calculator` - 공개 범위: **Public** (무료 계정은 공개 저장소여야 합니다) 4. 화면의 **uploading an existing file** 글자를 누릅니다. 안 보이면 **Add file → Upload files**를 누릅니다. 5. `index.html`을 끌어다 놓고 아래 초록색 **Commit changes**를 누릅니다. 6. 위쪽 메뉴 **Settings** → 왼쪽 메뉴 **Pages**를 누릅니다. 7. **Source**에서 Deploy from a branch를 고릅니다. 8. **Branch**에서 `main`, 폴더는 `/ (root)`를 고르고 **Save**를 누릅니다. 9. 몇 분 뒤 새로고침하면 사이트 주소가 나타납니다. 주소는 보통 아래 모양입니다. 이 주소를 네이버 카페에 붙여넣으면 됩니다. ``` https://내아이디.github.io/margin-calculator/ ``` ## 주의할 점 - **파일 이름:** `index (1).html`처럼 바뀌었으면 `index.html`로 고친 뒤 올리세요. - **공개 범위:** 올린 파일은 누구나 볼 수 있으니 비밀번호나 개인정보는 넣지 마세요. - **주소가 안 열릴 때:** "404"가 나오면 잠시 기다린 뒤 다시 열고, 파일 이름과 8번 설정을 확인하세요. - **코드를 보고 싶을 때:** 파일을 마우스 오른쪽 클릭 → **연결 프로그램 → 메모장**으로 열면 됩니다. 막히는 화면이 있으면 캡처해서 보내 주세요.
